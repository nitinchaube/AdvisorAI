# AdvisorAI

**Authors: Paras Jadhav, Nitin Chaube, Keval Sompura**

AdvisorAI is an AI-powered academic advisor built for Stevens Institute of Technology. Students can ask questions about courses, professors, degree requirements, and career opportunities through a conversational chat interface. The system retrieves answers from a Stevens-specific knowledge base, and when it does not have enough information, it searches the web in real time. On top of the chatbot, the application includes a job and internship search, resume parsing, course and faculty browsing with reviews, and a personal profile with a public portfolio page.

## Features

**AI Chatbot**
Conversational interface powered by LangGraph. Queries are routed, retrieved from a vector database, optionally supplemented with a live web search, generated by an LLM, and then self-evaluated with a reflection step. Conversations are saved and browseable in chat history.

**Course Explorer**
Browse all Stevens courses, view detailed descriptions, and read or submit reviews.

**Faculty Directory**
Browse faculty profiles including research interests, contact information, and student ratings.

**Job and Internship Search**
Continuously updated listings scraped from the SimplifyJobs GitHub repositories. Searchable and filterable directly in the app.

**Resume Parsing**
Upload a PDF or DOCX resume. The backend extracts and structures the content using an LLM and stores it on the user's profile. The parsed resume is then available as context to the chatbot.

**User Profiles and Portfolios**
Each user has a profile page and a public-facing portfolio accessible via a custom URL (`/portfolio/your-name`).

**Admin Dashboard**
Manage courses, faculty, and users. Manually trigger the job scraper and inspect vector database collections.

**Theme Support**
Light and dark mode throughout the application.

## How the AI Works

When a user sends a message, it travels through a LangGraph pipeline:

1. **Router** — Classifies the query as domain-specific (Stevens courses, faculty, etc.), general, or blocked (harmful/off-topic).
2. **Safety Gate** — Blocks queries that are inappropriate or outside the app's scope.
3. **Gather Information** — Runs in parallel:
   - `HistoryAgent` retrieves relevant past conversation turns.
   - `ChromaAgent` searches the vector database for Stevens-specific knowledge.
   - `GeneralAgent` handles purely general questions that do not need retrieval.
4. **Evaluate** — Assesses whether the gathered information is sufficient to answer.
5. **Web Search** — If the context is insufficient, `WebAgent` queries DuckDuckGo, fetches the top results, and extracts clean text.
6. **Generate** — The LLM synthesizes a final answer from all available context (history, vector results, web content, user resume).
7. **Reflect** — The response is scored 1–10. If the score is below 7, the answer is automatically refined.
8. **Save** — The conversation turn is saved to MongoDB.

Responses are streamed to the frontend using Server-Sent Events.

**Vector Database**

Stevens knowledge is stored in three ChromaDB collections:
- `AllCourseRelatedData`
- `AllFacultyGeneralInformation`
- `AllFacultyResearchInformation`

Embeddings are generated with HuggingFace `all-MiniLM-L6-v2` and persisted locally in `backend/VectorDB/`.

**Job Scraper**

A background thread runs every N hours (configurable) and fetches the README files from the `SimplifyJobs/New-Grad-Positions` and `SimplifyJobs/Summer2026-Internships` GitHub repositories. It parses the HTML tables and saves the results to `jobs.csv` and `internships.csv`.

## Getting Started

### Prerequisites

- Python 3.12
- Node.js 18+
- MongoDB instance (local or Atlas)
- Google Gemini API key or OpenAI API key
- Firebase project (for authentication)

### Backend Setup

```bash
cd AdvisorAI-Web/backend

# Create and activate a virtual environment
python -m venv venv

# Windows
venv\Scripts\activate

# macOS / Linux
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt
```

### Frontend Setup

```bash
cd AdvisorAI-Web/frontend
npm install
```

### Environment Variables

**Backend** — create `AdvisorAI-Web/backend/.env`:

```env
# Flask
SECRET_KEY=your_secret_key
JWT_SECRET_KEY=your_jwt_secret

# MongoDB
MONGO_URI=mongodb+srv://...
MONGO_DB_NAME=AdvisorAI

# LLM
LLM_PROVIDER=gemini          # or openai
GEMINI_API_KEY=your_key
OPENAI_API_KEY=your_key      # optional fallback

# Vector Database
VECTORDB_DIR=./VectorDB

# Background scraper
SCRAPER_ENABLED=true
SCRAPER_INTERVAL_HOURS=6

# CORS
CORS_ORIGINS=http://localhost:5173
```

**Frontend** — create `AdvisorAI-Web/frontend/.env.local`:

```env
VITE_FIREBASE_API_KEY=...
VITE_FIREBASE_AUTH_DOMAIN=...
VITE_FIREBASE_PROJECT_ID=...
VITE_FIREBASE_STORAGE_BUCKET=...
VITE_FIREBASE_MESSAGING_SENDER_ID=...
VITE_FIREBASE_APP_ID=...

VITE_API_BASE_URL=http://localhost:5000/api
```

## Running the App

**Option 1 — Scripts (recommended)**

On Windows (PowerShell):
```powershell
.\start_dev_servers.ps1
```

On macOS / Linux:
```bash
./start_dev_servers.sh
```

**Option 2 — Manually in two terminals**

Terminal 1 — Backend:
```bash
cd AdvisorAI-Web/backend
venv\Scripts\activate        # or source venv/bin/activate
python app.py
```

Terminal 2 — Frontend:
```bash
cd AdvisorAI-Web/frontend
npm run dev
```

The frontend will be at `http://localhost:5173` and the backend at `http://localhost:5000`.

## Deployment

The backend is containerized and deployed to **Google Cloud Run**.

```bash
# Build the image
docker build -t advisorai-backend ./AdvisorAI-Web/backend

# Push to Google Artifact Registry and deploy via Cloud Run
# (set environment variables as Cloud Run secrets/env vars)
```

The Dockerfile uses `python:3.12-slim`, installs dependencies, and runs the app with `uvicorn` (2 workers, port 8080).

The frontend is a static Vite build that can be hosted on Firebase Hosting, Vercel, or any CDN. Set `VITE_API_BASE_URL` to the Cloud Run URL before building.

```bash
cd AdvisorAI-Web/frontend
npm run build
```
